 SQL Employee Management Project

 Project Overview

This project is a complete SQL-based Employee Management System.  
It includes database creation, table design, data insertion, and advanced SQL queries for practice and analysis.

The project contains 146 SQL queries covering all major SQL concepts.


Technologies Used
- MySQL / SQL
- Relational Database Concepts



Project Structure

- schema.sql → Database & table creation (structure)
- data.sql → Employee data insertion
- queries.sql → 146 SQL practice queries
